# 2026-11-16

## 前端改版：参考即梦重构站点骨架与首页

目标是把画柚做成即梦（jimeng.jianying.com）那种「左侧窄导航 + 顶部搜索 + 浅灰底白卡片」的形态。

- **布局**：`layouts/user-layout.tsx` 改为 `bg-stone-50 / dark:bg-stone-950`，左侧插入
  `components/layout/app-side-nav.tsx`（88px，logo + 首页/生图/视频/画布/提示词/资产 + 底部设置）；
  画布项目页 `/canvas/:id` 仍然全屏，不渲染侧栏（与顶栏 hideHeader 同一正则）。
- **顶栏**：`components/layout/app-top-nav.tsx` 去掉横排导航与 logo，改成 64px 高、居中胶囊搜索框
  （提交跳 `/prompts?q=`），右侧保留主题/客服/头像；移动端保留 logo + 汉堡。
- **导航常量**：`constant/navigation-tools.ts` 补上 `image`，顺序变为 image/video/canvas/prompts/assets。
- **首页**：`pages/home/index.tsx` 整页重写——hero 标题 + 大输入卡（图片/视频切换、Ctrl+Enter 生成）
  + 4 条示例提示词 + CSS columns 瀑布流灵感墙（hover 有「做同款」回填提示词）。提交跳
  `/{image|video}?prompt=`。
- **参数直达**：`pages/image/index.tsx`、`pages/video/index.tsx` 启动时读 `?prompt=` 预填并清掉 query；
  `pages/prompts/index.tsx` 读 `?q=` 初始化关键词。
- **视觉统一**：image/video 主卡片 `rounded-2xl` + 极淡阴影、日志侧栏去边框透明化、生成按钮改右侧胶囊；
  assets/prompts/canvas 列表去掉 radial 网格背景、改 `bg-transparent`。
- **文案**：`i18n/locales/{zh-CN,en-US}.ts` 新增 `navigation.home`、`topNav.searchPlaceholder`，
  `home.*` 换成 hero/prompt/mode/suggestion/inspiration 一组新 key（旧的 description/start 等已删）。

验证：本机无 `node_modules`，只用 `npx esbuild` 对所有改动文件做过语法解析（通过），
**没有跑 tsc/build，也没有截图**；视觉需用户起 dev 后确认。

待办：图片/视频工作台仍是「左日志 + 输入 + 结果」三栏，没改成即梦的单列输入 + 瀑布流结果。
